# nomira-web

> **Alpha.** Hier entstehen das Referenz-Recipe für das nomira-OS und die
> Website, die Aufbau und Installation erklärt. Noch ist das Repo leer.

Das Recipe ist zugleich die Dokumentation: Die Website wird aus dem
Recipe und seinen Erläuterungen erzeugt.

Verwandte Repos: [nomira](https://github.com/Nomira-OS/nomira) (das
Build-Frontend), [nomira-cli](https://github.com/Nomira-OS/nomira-cli),
[nomira-image](https://github.com/Nomira-OS/nomira-image) (das
Basis-Image), [ci](https://github.com/Nomira-OS/ci) (gemeinsame CI).

## Lizenz

EUPL-1.2, siehe `LICENSES/`. Die Angaben je Datei stehen in `REUSE.toml`.
