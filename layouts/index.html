An immutable Arch Linux, built from a recipe and switched atomically.

What you get

  • Built from a recipe

    Ordinary commands in one file. Every build starts fresh, so nothing lingers.

  • Immutable

    The running system is read-only. Updates arrive whole, with a way back.

  • Freely configurable

    Any command, normal files in /etc. No new language to learn.

  • Plain Arch packages

    Unchanged, in the usual paths. The Arch Wiki mostly still applies.

From recipe to running system

  1. Write

    A YAML file lists the steps, in phases.

  2. Build

    Independent groups of a phase build at the same time.

  3. Check

    Two groups touching the same file stop the build.

  4. Switch

    bootc changes over atomically. The old state stays bootable.

Three tools, one system

Each one is useful on its own. Together they take a recipe to a running machine.

  • Frontend

    Builds the recipe with BuildKit, in parallel where it is safe. Works for any container image.

  • CLI

    One command builds and publishes the image: nomira build. bootc takes it from there.

  • Base images

    Start from the smallest Arch Linux that bootc can boot, with AppArmor and Flatpak. Your recipe adds the rest.
